# PLVOM

This repository contains the data and implementation code for the article:

**A Poisson Latent Variable Ordinal Model for Multiclass Link Prediction in Dynamic Directed Weighted Networks**

## Files

- `plvom_simulation.py`  
  Python implementation of the PLVOM estimation procedure and Monte Carlo simulation experiments.

- `Airport Flight Network.xlsx`  
  Dataset used for the empirical analysis of the airport flight network.

- `Journal Citation Network.xlsx`  
  Dataset used for the empirical analysis of the journal citation network.

## Requirements

The code is implemented in Python and mainly requires:

- NumPy
- pandas
- SciPy
- openpyxl

## Usage

Run the simulation code using:

```bash
python plvom_simulation.py
